# Quick Work Log 手動確認

対象環境はWindows版の安定版Chromeです。Google CloudでCalendar APIを有効化し、Chrome拡張機能用OAuthクライアントIDを `quick-work-log/manifest.json` の仮値へ設定してから実施します。

1. `npm test` と `npm run check` が成功することを確認する。
2. `chrome://extensions` でデベロッパーモードを有効にし、`quick-work-log` を読み込む。
3. ツールバーアイコンと `Alt+Shift+C` でポップアップが開き、作業名へフォーカスされることを確認する。
4. 未認証時に画面を開いただけでは認証画面が開かず、再認証ボタンが表示されることを確認する。
5. 再認証ボタンから認証し、書き込み可能なカレンダーだけが一覧に表示されることを確認する。
6. カテゴリを追加・編集・削除し、ポップアップを閉じて再度開いても保存されることを確認する。
7. 必須項目未入力、無効日時、終了日時の逆転で登録できず、項目付近に文章のエラーが出ることを確認する。
8. 正常な入力で登録し、Googleカレンダーにタイトル、日時、メモ、場所、色が反映されることを確認する。
9. 登録中の連続クリックとEnter操作で要求が一件だけになることを確認する。
10. 認証失効、通信切断、権限不足で入力が保持され、次の操作が表示されることを確認する。

未実施の項目は成功扱いにせず、実施日時・Chromeバージョン・結果・既知の制約を記録します。
